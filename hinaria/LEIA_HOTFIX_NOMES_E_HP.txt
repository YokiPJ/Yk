HINARIA V7 - HOTFIX ETIQUETAS/HP NO ANDROID
==========================================

O QUE FOI CORRIGIDO
- Nomes de Bram, Yoki e monstros apareciam fora do lugar na WebView com DPI alto.
- Agora as coordenadas usam pixels CSS da tela (getBoundingClientRect), nao a resolucao interna do WebGL.
- Barras de vida dos monstros nao tinham elemento de preenchimento no HTML; agora atualizam com o HP e mudam de cor.
- Etiquetas somem quando o monstro fica fora da camera.
- Sem mudanca no dano, maximo de vida, quests, controles ou vila.

COMO APLICAR NO TEU CODESPACES (SEM REINSTALAR JAVA/SDK)
1) Envie HINARIA_V7_CORRECAO_NOMES_HP_PATCH.zip para /workspaces/Apk no Codespaces.
2) Rode no terminal:

   cd /workspaces/Apk
   unzip -o HINARIA_V7_CORRECAO_NOMES_HP_PATCH.zip
   cd HINARIA_V7_ANDROID
   node tests/test_entity_tags.mjs
   npm run android:debug

3) Se passar, baixe HINARIA_V7_ANDROID/APK_GERADO/HINARIA_V7_DEBUG.apk.
4) Instale o APK atualizado no celular. Se o Android rejeitar a atualizacao por assinatura diferente,
   faça backup de qualquer progresso antes de desinstalar a versao antiga.

O PATCH usa os arquivos do ultimo projeto Android V7. Ele sobrescreve apenas
index.html, hud.js, combat.js, npc.js e cria o teste test_entity_tags.mjs.
