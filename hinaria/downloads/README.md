# Arquivos compilados

- `HinariaMotion.jar`: gerador Java 17+ pronto, com referência embutida.
- `HINARIA_MOBILE_1.2.2_DEBUG.apk`: gerado localmente por `npm run build:android`; APKs não são versionados no ramo principal.
- `SHA256SUMS.txt`: atualizado após as compilações.

O APK publicado está na [release 1.2.2](https://github.com/YokiPJ/Yk/releases/tag/v1.2.2). No portal local, o botão oferece o APK compilado quando ele existe; caso contrário, direciona ao anexo da release.
