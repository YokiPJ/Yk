HINÁRIA V7 — VILARRUBRA REORGANIZADA — PACOTE PARA APK
======================================================

ESTE ZIP É UM PROJETO PARA GERAR APK, NÃO É O ARQUIVO .APK JÁ COMPILADO.
Usa a V7 fornecida no ZIP HINARIA_V7_VILARRUBRA_REORGANIZADA.zip.
Inclui a nova disposição dos modelos da vila, correções de HP/missões e analógico.

PASSO A PASSO (WINDOWS)
1) Extraia a pasta HINARIA_V7_ANDROID inteira. Não rode de dentro do ZIP.
2) Instale Node.js LTS, Android Studio (com Android SDK) e JDK 21.
3) Configure o Android SDK no Android Studio. Se necessário, defina ANDROID_HOME.
4) Dê dois cliques em GERAR_APK_WINDOWS.bat.
5) Com o processo finalizado, veja: APK_GERADO\HINARIA_V7_DEBUG.apk
6) Transfira o APK ao celular. Autorize a instalação de apps externos, se solicitado.

PASSO A PASSO MANUAL (WINDOWS, CMD na pasta do projeto)
  npm install
  npm run build:web
  npx cap add android       (somente na primeira vez; se android/ já existir, pule)
  npx cap sync android
  npm run android:debug

Alternativa no Android Studio: após sincronizar, rode `npx cap open android`,
e escolha Build > Build APK(s).

OBSERVAÇÕES IMPORTANTES
* É preciso internet DURANTE npm install/instalação do SDK Android.
* O jogo DENTRO do APK usa Three.js local e fotos locais: funciona offline
  depois de compilado, sem acessar unpkg.com ou Google Fonts.
* É um APK DEBUG, para teste e instalação direta. Para publicar na Play Store,
  será necessário gerar um AAB RELEASE e assinar a compilação.
* O nome do pacote é br.com.hinaria.rpg (mude antes de publicar).
* O jogo foi copiado da V7 original; nenhum modelo/código de gameplay foi
  substituído pelo HTML legado.
* Não há compilador Android/SDK configurado no ambiente de entrega; o APK
  nativo NÃO foi compilado nem testado em telefone aqui.
* Não instale npm na pasta src. Execute comandos na pasta principal.

ERROS COMUNS
- "SDK location not found": abra a pasta android no Android Studio e instale SDK.
- "JAVA_HOME": use JDK 21 compatível com Capacitor 7.
- "three.module.js not found": rode npm install primeiro.
- Tela preta: tente o jogo em dispositivo com WebGL2 e confira o logcat.

FONTES E ARQUIVOS
- Código do jogo V7: index.html, src/, assets/
- Builder offline: tools/build-web.mjs
- Config Android: capacitor.config.json
- Scripts: package.json
