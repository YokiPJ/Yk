# HINÁRIA V7.4 — Interface Mobile

Esta é uma versão COMPLETA da base V7.3, preservando mapas, personagens, missões, Arsenal e controles. Mudanças específicas em `assets/ui/mobile-v74.css`, `src/quest/questUI.js`, `src/player/player.js`, `src/core/loop.js`, `src/ui/hud.js` e ferramentas de build.

**Mobile:** HUD compacto, botão para expandir objetivos, minimapa no topo direito, controles de 49–61 px no canto inferior direito, joystick destacado no canto inferior esquerdo, chat recolhível, menus maiores e safe areas. No desktop layout normal é preservado.

**Codespaces:** mantenha a pasta `android/` atual (contém o projeto nativo). Baixe o ZIP, extraia em `/workspaces/Apk`, faça backup da pasta atual e copie os arquivos da pasta `HINARIA_V7_ANDROID` nova sobre sua instalação (não substitua `android/`). Use os comandos da mensagem de entrega.

**Verificação:** o jogo exibe `V7.4 · INTERFACE MOBILE · 31OUT`; o APK deve ser `APK_GERADO/HINARIA_V7_4_INTERFACE_MOBILE.apk`. Isso NÃO substitui teste em celular real.
